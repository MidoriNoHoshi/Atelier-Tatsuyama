# Atelier Tatsuyama | Personal Archive

> **Status:** [ACTIVE]  
> **Vibe:** Tech-Industrial / CRT Aesthetic

Project started during 2nd year of Highschool in Norway.
Looking back I was so invested in it because it was an escape from the terribly uninspiring day and I was greatly inspired by the aesthetics of various computer games.

Titanfall 2, Homeworld 2, Armored Core VI, Arknights, SNES Metal Warriors

I hope to create my own space of inspiration and creativity with this website, and should anyone somehow come across it I hope that it inspires. . . somehow

### Astro Commands

Just a personal reminder
All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
